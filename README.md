# Sleep Ritual™

Animated, responsive ecommerce landing page concept for **Sleep Ritual™ Deep Sleep Pillow & Room Mist**.

## Features
- Premium navy/cream/purple visual system
- CSS-rendered animated product bottle and mist
- Responsive desktop, tablet and mobile layouts
- Scroll reveal animations and desktop product parallax
- Benefits, ingredients, usage, lifestyle, testimonials, comparison, offer and FAQ sections
- Sticky mobile Order Now CTA
- SEO description and semantic HTML
- GitHub Pages compatible — no build process required

## Publish with GitHub Pages
Open repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Before commercial launch
Replace demo testimonials with verified customer reviews, connect Order Now to a real ecommerce checkout, replace placeholder policies/contact details, and ensure final product claims, directions, ingredient disclosures and safety statements match the tested manufactured formula and applicable regulations.
